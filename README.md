# DiveHubApp Legacy

Legacy Android application developed for Dive Hub scuba diving center.

The project was built with Java, Eclipse, Android SDK, XML and SQLite.

## Main Features

- Dive site information
- PADI, CMAS and DAN course information
- Diving services
- Photo gallery
- Contact form
- Offline digital dive logbook

## Digital Logbook

Users can store and review dive records locally, including:

- Dive site
- Depth
- Dive time
- Date
- Tank pressure
- Exposure protection
- Weight
- Dive leader
- Buddy
- Notes

## Tech Stack

- Java
- Android SDK
- Eclipse
- XML
- SQLite

## Status

This project is archived and no longer actively maintained.

It is kept as part of my software development portfolio to demonstrate my earlier Android development work and the evolution of the Dive Hub software ecosystem.

A modern successor can be developed using .NET MAUI and ASP.NET Core.
